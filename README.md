# Capstone-Project---Database-Design-For-An-E-Commerce-Store
SQL capstone project focused on designing and analyzing an E-commerce database using table creation, data insertion, and advanced SQL queries to generate business insights and sales analysis.

---

## Objectives
- Design a structured relational database for an E-commerce store
- Manage and organize business data efficiently
- Perform sales and customer analysis using SQL queries
- Generate business insights for decision-making

---

## Database Modules
- Customers
- Products
- Orders
- Order Items
- Payments

---

## SQL Concepts Used
- CREATE TABLE
- INSERT INTO
- SELECT Statements
- WHERE Clause
- GROUP BY
- ORDER BY
- Aggregate Functions
- JOINS
- Subqueries etc

---

## Business Problems Solved
- Total Revenue Analysis
- Revenue by Product
- Best Selling Products
- Top Customer by Spending
- Cancelled Orders Count
- Most Used Payment Method
- Monthly Sales Analysis
